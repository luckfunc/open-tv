# OpenTV

OpenTV is a third-party Android TV launcher for FFALCON TV users. It has been tested on the Peng 7 Plus.

[简体中文](README.md) · [Download APK](https://github.com/luckfunc/open-tv/releases/download/v0.3.15/OpenTV-0.3.15-guard.apk) · [Report an issue](https://github.com/luckfunc/open-tv/issues)

## Features

- App grid, sorting, and hiding.
- Daily wallpapers, photo wallpapers, and daily photo rotation.
- Scan a QR code to upload photos and change wallpapers or app icons from your phone.
- Remote control navigation and an in-app first-time setup guide.

## Installation

1. Download the APK, transfer it to your TV, and confirm installation.
2. Open OpenTV. Follow the guide to enable ADB debugging and approve the TV's authorization prompt.
3. Complete setup, then check that the remote's Home button returns to OpenTV.

This is a test release. Other FFALCON models have not been individually verified. Keep your TV's original launcher. First-time setup requires ADB debugging support.

Install updates over the existing app. Do not uninstall or clear data first, as this can remove your photos, wallpapers, and settings.
