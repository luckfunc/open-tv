# OpenTV

OpenTV 是一款面向雷鸟电视用户的第三方 Android 电视桌面，目前已在鹏 7 Plus 上测试。

[English](README.en.md) · [下载 APK](https://github.com/luckfunc/open-tv/releases/download/v0.3.15/OpenTV-0.3.15-guard.apk) · [问题反馈](https://github.com/luckfunc/open-tv/issues)

## 功能

- 应用排列、排序与隐藏。
- 每日壁纸、照片壁纸与照片轮换。
- 手机扫码上传照片、更换壁纸和应用图标。
- 遥控器操作与应用内首次设置引导。

## 安装

1. 下载 APK，传到电视并确认安装。
2. 打开 OpenTV，按引导开启 ADB 调试并确认电视上的授权提示。
3. 完成设置后，按遥控器主页键检查是否返回 OpenTV。

当前为测试版，其他雷鸟机型尚未逐一验证，请保留电视原有桌面。首次设置需要电视支持 ADB 调试。

升级请直接覆盖安装，不要先卸载或清除数据，以免丢失照片、壁纸和设置。
